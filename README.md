## What is what?

- **[Skill](https://aaaa.fyi/glossary/claude-skills)** — a reusable `SKILL.md` instruction set that teaches an agent one task.
- **[MCP server](https://aaaa.fyi/glossary/mcp-server)** — exposes tools, APIs and data to an agent over the Model Context Protocol.
- **[Plugin](https://aaaa.fyi/glossary/agent-skill)** — a bundle of skills, subagents, hooks and MCP servers, installed as one package.
- **Subagent** — a specialized single-file assistant you delegate focused tasks to.
